## Status language

- Implemented means the capability exists in the software prototype.
- Hardware validation means the schema or interface exists, but the physical device still needs bench and field evidence.
- Demo model means the ML pipeline and integration work, but the current artifact is rejected for field release.
- Pump gated means irrigation advice exists while automatic actuation remains outside the present safety boundary.

## PowerPoint placement

The source template is 16:9. Insert an asset without cropping and preserve its aspect ratio. The PNG files can fill the slide canvas. If the official title and footer must remain visible, place the SVG inside the body area and remove its top title before the final deck export.
